# Five Sols on Mars

A browser game for the NASA Space Apps Challenge 2026 challenge
[Build a Junior Astronaut Mission Trainer](https://www.spaceappschallenge.org/2026/challenges/junior-astronaut-mission-trainer/).

Built with Godot 4.7.2 (Compatibility renderer, single-threaded Web export).

## Build and publish

```sh
scripts/publicar.sh
```

Exports the `Web` preset to `build/web/` and force-pushes it to the `gh-pages` branch.
